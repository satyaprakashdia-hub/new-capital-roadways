# New Capital Roadways — Website

A lightweight, responsive static website for New Capital Roadways Packers & Movers.

## Files

- `index.html` — website structure/content
- `style.css` — all visual styling and responsive layout
- `config.js` — **edit this file for business details, phone numbers and Google Maps link**
- `script.js` — functionality (WhatsApp, phone links, mobile menu)
- `assets/original-signboard.jpg` — uploaded NCRW signboard used in the website

## How to edit

Open `config.js` in any code editor.

Change:
- company name
- address
- mobile numbers
- landlines
- primary WhatsApp number
- Google Maps link

You can also edit text directly in `index.html` and the design in `style.css`.

## Google Maps

The supplied Google Maps link is already configured in `config.js`. The mapped location resolves to Plot No. 31, Near Shiv Mandir, National Highway 5, Pohala, Bhubaneswar, Odisha 751032, India.

## Hosting

This is a normal static website. It does not require a server, database or paid software.

It can be hosted on services such as GitHub Pages, Netlify or Cloudflare Pages, and can use a custom domain such as:

`newcapitalroadways.in`
or
`newcapitalroadways.com`

Domain registration itself may cost money; the website files can remain free to host depending on the hosting provider.

## Browser support

The site uses standard HTML, CSS and JavaScript and is designed for current Chrome, Safari, Edge and Firefox on phones, tablets and desktops.
