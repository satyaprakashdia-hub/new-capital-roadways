# NCRW FAQ Assistant

This version keeps the existing NCRW website unchanged and adds a lightweight FAQ assistant.

- No API key
- No backend
- No monthly AI/API charge
- Works on phones, tablets, Windows PCs and laptops
- Runs directly in the browser
- Uses the existing NCRW phone number and business information

Upload/replace the website files in the GitHub Pages repository, keeping the `assets/` folder exactly as included.
